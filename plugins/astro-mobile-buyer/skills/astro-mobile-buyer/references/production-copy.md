## Tone Patterns yang Dipakai di Production

Dari copy aktual di atas, terlihat pola konsisten:
- **Panggil buyer "kamu"** — bukan "Anda", bukan "lo/gue"
- **Gunakan emoji secukupnya** — "😢" untuk OOS, "🎉" untuk milestone
- **"Ups"** untuk error ringan (bukan "Maaf" atau "Error")
- **"Yuk"** untuk ajakan/encourage
- **"Nih"** untuk informasi ramah
- **"Duh"** untuk empty state dengan empati
- **Sentence case** untuk semua label — bukan ALL CAPS (kecuali constant names di code)
- **Spesifik + actionable** — error selalu punya next step
- **Short & punchy** — tidak verbose, maksimum 1-2 kalimat
